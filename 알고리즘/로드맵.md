## 📌 섹션 1: 오리엔테이션 및 C++ 필수 개념

**학습 목표:** C++의 코테 특화 기능 이해 및 수학적 기초 구축

### 주요 주제
- **강의 가이드**: 공부 방법, 주의사항, 질문법, 직장인 학습 팁, 대기업 합격 수기
- **언어 특성**: 
  - C++이 코테에 좋은 이유
  - `split()` 구현
  - `unique()`를 활용한 중복 제거
- **메모리와 포인터**:
  - 주소와 역참조
  - Array to pointer decay 원리
- **수학적 기초**:
  - 재귀함수 (Recursion)
  - 순열 (`next_permutation` 및 재귀 구현)
  - 조합 (Combination)

## 📌 섹션 3: 그래프 이론과 탐색

**학습 목표:** 코딩테스트의 **핵심** - 그래프 탐색 완전 정복

### 주요 주제
- **그래프 기초**:
  - 정점 (Vertex), 간선 (Edge), 가중치
  - 인접 행렬 vs 인접 리스트
- **트리 구조**:
  - 이진 트리 (Binary Tree)
  - 이진 탐색 트리 (BST)
  - 트리 순회 (전위/중위/후위)
- **탐색 알고리즘**:
  - DFS (깊이 우선 탐색)
  - BFS (너비 우선 탐색)
- **실전 테크닉**:
  - 방향 벡터를 이용한 맵 탐색
  - 연결된 컴포넌트 (Connected Component)

### 폴더: `03_그래프이론과_탐색/`
- `인접행렬_인접리스트.cpp`
- `DFS.cpp`
- `BFS.cpp`
- `트리순회.cpp`
- `방향벡터_맵탐색.cpp`

## 📌 섹션 4: 완전 탐색과 백트래킹

**학습 목표:** 모든 경우의 수를 효율적으로 탐색

### 주요 주제
- **브루트 포스 (Brute Force)**: 모든 경우를 확인하는 전략
- **백트래킹**: 탐색 중 조건에 맞지 않으면 되돌아가는 원리
- **상태 복원 기법**: 상태를 변화시켰다가 다시 되돌리기
- **문제 전략**:
  - 문제의 단순화
  - 테스트 케이스 반례 찾기
  - 전역 변수 사용 주의점

### 폴더: `04_완전탐색과_백트래킹/`
- `브루트포스.cpp`
- `백트래킹.cpp`

- **응용**: 비트마스킹을 이용한 경우의 수 계산 및 매개변수 활용

## 📌 섹션 6: 그리디, 라인스위핑, 투포인터

**학습 목표:** 특정 규칙으로 효율적 탐색

### 주요 주제
- **그리디 (Greedy)**:
  - 현재 시점의 최선이 전체 최적이 되는 조건
  - 증명 가능한 그리디의 조건
- **라인 스위핑 (Line Sweeping)**:
  - 선을 긋듯이 데이터를 한 번 훑으며 처리
- **투 포인터 (Two Pointers)**:
  - 두 인덱스를 조절하며 O(N)에 구간 탐색

### 폴더: `06_그리디_라인스위핑_투포인터/`
- `그리디.cpp`
- `라인스위핑.cpp`
- `투포인터.cpp`

## 📌 섹션 7: 이분 탐색과 LIS

**학습 목표:** 정렬 데이터에서의 고속 탐색과 동적 수열 최적화

### 주요 주제
- **이분 탐색 (Binary Search)**:
  - 탐색 범위를 절반씩 줄여 O(log N)에 도달
  - 직접 구현과 STL 활용
- **LIS (최대 증가 부분 수열)**:
  - O(N²) 풀이 (DP)
  - O(N log N) 최적화 풀이

### 폴더: `07_이분탐색과_LIS/`
- `이분탐색.cpp`
- `LIS.cpp`

---

## 📌 섹션 8: 동적 계획법 (DP)

**학습 목표:** 중복 계산을 피하고 최적 부분 구조 활용

### 주요 주제
- **DP 기초**:
  - 점화식 세우기
  - Top-down (메모이제이션) vs Bottom-up (태뷸레이션)
- **심화 유형**:
  - 냅색 (Knapsack) 알고리즘 (0/1, 무제한)
  - 실수형 연산의 한계와 주의
- **특수 기법**:
  - Meet in the Middle (탐색 범위를 절반으로 나누어 합치기)

### 폴더: `08_동적계획법_DP/`
- `DP_기초.cpp`
- `냅색_Knapsack.cpp`
- `MeetInTheMiddle.cpp`

## 📌 섹션 9: 심화 그래프와 최단 거리

**학습 목표:** 복잡한 그래프 문제를 전문 알고리즘으로 해결

### 주요 주제
- **펜윅 트리 (Fenwick Tree)**:
  - 효율적인 구간 합 업데이트
  - 세그먼트 트리와의 비교
- **최단 거리 3대장**:
  - **다익스트라 (Dijkstra)**: 단일 시작점, 양수 가중치
  - **플로이드-워셜 (Floyd-Warshall)**: 모든 정점 간 최단 거리
  - **벨만-포드 (Bellman-Ford)**: 음수 가중치 포함

### 폴더: `09_심화그래프와_최단거리/`
- `펜윅트리.cpp`
- `다익스트라.cpp`
- `플로이드워셜.cpp`
- `벨만포드.cpp`

## 📌 섹션 10: 마무리 특강

**학습 목표:** 특수 자료구조와 문자열 알고리즘 완성

### 주요 주제
- **유니온 파인드 (Union-Find)**:
  - 상호 배타적 집합 (Disjoint Set) 관리
  - 합치기 (Union)와 찾기 (Find)
  - 경로 압축과 랭크 최적화
- **LCS (최장 공통 부분 수열)**:
  - 두 문자열 간의 공통 부분 찾기
  - DP를 이용한 구현
  - 실제 수열 복원하기

### 폴더: `10_마무리특강/`
- `유니온파인드.cpp`
- `LCS.cpp`

## 🎯 학습 팁

1. **각 섹션마다 백준 문제 풀기**: 이론만 배우지 말고 실제 문제로 검증
2. **작은 입력부터 테스트**: 손으로 계산한 후 코드 작성
3. **시간 복잡도 항상 고려**: "이 코드가 제한시간 내에 끝날까?"
4. **여러 번 풀기**: 같은 문제를 1주일 뒤, 1개월 뒤 다시 풀어보기
5. **코드 리뷰**: 다른 사람의 풀이와 비교하며 배우기
