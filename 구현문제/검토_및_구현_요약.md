### 문제1: 비트 연산과 형 변환을 활용한 권한 판별 프로그램
**상태**: ✓ 수정 완료

**요구사항 충족**:
- ✓ 비트 OR 연산으로 권한 누적
- ✓ 비트 AND 연산으로 포함 여부 판별
- ✓ **명시적 형 변환 (bool)** 추가: `(bool)((permission & mask) != 0)`
- ✓ `std::boolalpha` 사용
- ✓ `bitset<8>` 2진수 출력
- ✓ 주석으로 요구사항 명시

**수정 사항**:
- `(bool)` 명시적 형 변환 추가
- 변수명, 기능별 주석 추가

### 문제2: 반복문과 조건문을 활용한 구구단 출력 프로그램
**상태**: ✓ 완전 재작성

**이전 문제**: 문제1 내용이 복사되어 있어 구구단 로직이 전혀 없었음

**요구사항 충족**:
- ✓ `do-while` 루프로 유효 입력 반복
- ✓ 시작 단 > 끝 단 시 "잘못된 입력입니다." 출력
- ✓ 범위 검사 (2 이상 9 이하)
- ✓ `continue`로 홀수 결과만 출력
- ✓ `break`로 50 초과 시 해당 단 중단
- ✓ 총 개수 카운팅
- ✓ 주석으로 각 기능 명시

**핵심 코드**:
```cpp
do-while {
    // 입력 유효성 검사 (시작 <= 끝, 2~9 범위)
}
for (각 단) {
    for (i=1~9) {
        if (result > 50) break; // 50 초과 시 중단
        if (result % 2 == 0) continue; // 짝수 건너뛰기
        // 출력 및 count 증가
    }
}
```

### 문제3: 예외 처리와 캡슐화를 활용한 은행 계좌 관리 프로그램
**상태**: ✓ 수정 완료

**요구사항 충족**:
- ✓ `Account` 클래스 (private 멤버, public 메서드)
- ✓ 입금: **금액 ≤ 0 시** `throw int` → `catch(int)` "입금 오류: 0보다 큰 금액을 입력하세요."
- ✓ 출금: 잔액 부족 시 `throw float` → `catch(float)` "출금 오류: 잔액이 부족합니다."
- ✓ **`catch(...)` 추가**: 예상치 못한 예외 처리
- ✓ `switch` 문으로 메뉴 처리
- ✓ 종료 시 최종 계좌 정보 출력
- ✓ 주석으로 각 예외 처리 명시

**수정 사항**:
- 입금 조건: `in_money < 0` → `in_money <= 0` (0도 오류)
- `catch(...)` 추가
- 변수명 개선 (Name → name, Money → balance)
- 주석 추가

### 문제4: 클래스를 활용한 학생 성적 관리 프로그램
**상태**: ✓ 완전 재작성

**이전 문제**: 문제1 내용이 복사되어 있어 Student 클래스 로직이 전혀 없었음

**요구사항 충족**:
- ✓ `Student` 클래스 (private 멤버: 이름, 점수 배열 3개, 평균)
- ✓ 점수 입력 시 0~100 유효성 검사
- ✓ 범위 벗어나면 "유효하지 않은 점수입니다." 출력 후 재입력
- ✓ **명시적 형 변환 (double)**: `(double)(합) / 3.0`
- ✓ 3명 학생 객체 생성, 입력받기
- ✓ 전체 학생 정보 출력
- ✓ 최고 평균 학생 출력
- ✓ 소수점 2자리 출력 (`fixed`, `setprecision(2)`)
- ✓ 주석으로 각 요구사항 명시

**핵심 코드**:
```cpp
class Student {
private:
    string name;
    int scores[3];
    double average;

    void calculate_average() {
        average = (double)(scores[0] + scores[1] + scores[2]) / 3.0;
    }
};
```

## 🆕 구현 결과 (문제 5~6)

### 문제5: 상속과 다형성을 활용한 탈것 관리 프로그램
**상태**: ✓ 완전 구현

**구현 내용**:

**부모 클래스 `Vehicle`**:
- protected 멤버: name, max_speed, current_speed
- public 메서드: print_info(), stop()
- **virtual accelerate()**: 자식 클래스에서 override

**자식 클래스**:
- `Car`: 가속 시 +20 (최대 속도 200)
- `Bicycle`: 가속 시 +5 (최대 속도 30)
- `Airplane`: 가속 시 +100 (최대 속도 900)

**요구사항 충족**:
- ✓ 부모 클래스 virtual 함수 선언
- ✓ 각 자식 클래스에서 override
- ✓ 최대 속도 초과 시 최대 속도로 고정
- ✓ Vehicle* 포인터 배열[3] 사용
- ✓ 동적 할당 (`new`)
- ✓ 각 탈것 3회 가속 후 정보 출력
- ✓ 자전거 추가 테스트 (4회 가속으로 최대 속도 도달 확인)
- ✓ 메모리 해제 (`delete`)
- ✓ 주석으로 각 요구사항 명시

**출력 예시**:
```
[자동차] 엔진 가속: 현재 속도 20
[자동차] 엔진 가속: 현재 속도 40
[자동차] 엔진 가속: 현재 속도 60
-> 자동차 | 최대 속도: 200 | 현재 속도: 60
...
메모리 해제 완료
프로그램을 종료합니다.
```

### 문제6: 상속과 다형성을 활용한 카페 주문 관리 프로그램 (종합)
**상태**: ✓ 완전 구현

**구현 내용**:

**부모 클래스 `MenuItem`**:
- protected 멤버: name, price
- public 메서드: get_name(), get_price()

**자식 클래스 `CafeItem`** (상속: MenuItem → CafeItem):
- 추가 멤버: category (커피, 음료, 음식 등)
- 메서드: get_category(), print_info()

**핵심 클래스 `CafeManager`**:
- private 멤버: menu_list(vector), balance(10000), order_history
- public 메서드:
  - add_menu(): 메뉴 등록
  - print_menu(): 메뉴 출력
  - order(): 주문 처리 (예외 처리 포함)
  - check_balance(): 잔액 조회
  - print_order_history(): 주문 내역 출력

**요구사항 충족**:

1. **클래스 구조**:
   - ✓ MenuItem 부모 클래스 (멤버 private, 메서드 public)
   - ✓ CafeItem 자식 클래스 (상속)
   - ✓ CafeManager 클래스

2. **조건문 & 반복문**:
   - ✓ `switch` 문으로 메뉴 선택
   - ✓ `while` 루프로 반복 실행
   - ✓ `for` 루프로 메뉴 출력

3. **명시적 형 변환**:
   - ✓ `(float)` 부족 금액 계산: `float shortage = (float)(total_price - balance);`

4. **예외 처리** (3가지 모두 구현):
   - ✓ **수량 오류**: 수량 ≤ 0 시 `throw int` → `catch(int)` "수량 오류: [값]은(는) 유효하지 않습니다."
   - ✓ **잔액 부족**: `throw float` → `catch(float)` "결제 오류: [금액]원이 부족합니다."
   - ✓ **예상치 못한 예외**: `catch(...)` "알 수 없는 오류가 발생했습니다."

5. **기능**:
   - ✓ 메뉴 자동 등록 (6개 항목)
   - ✓ 메뉴 조회
   - ✓ 주문 처리
   - ✓ 잔액 조회
   - ✓ 주문 내역 조회
   - ✓ 반복 실행 (종료 선택 시 종료)

## 📝 주석 규칙

모든 파일에 다음과 같은 방식으로 주석 작성:

1. **요구사항 주석**: `// [요구사항] ...`
2. **변수명 주석**: 변수 선언 옆에 역할 명시
3. **기능 주석**: 복잡한 로직에 한 줄 설명

**예시**:
```cpp
int permission = 0;          // 누적 권한값 (비트 OR 연산)

// [요구사항] 비트 AND 연산으로 권한 포함 여부 판별
```
